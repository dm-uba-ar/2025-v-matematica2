### Régimen de promoción

- Habrá dos exámenes parciales y un recuperatorio para cada uno de ellos al final del curso. No se podrá recuperar el mismo examen dos veces.
- Aún habiendo aprobado el parcial, se puede rendir el recuperatorio correspondiente para modificar la nota. En este caso el parcial aprobado caduca, como si no se lo hubiera rendido.
- La nota final será el promedio de las notas obtenidas en los exámenes aprobados.
